# منصة نحن المتميزون

منصة تعليمية عربية ثابتة متعددة الصفحات للفرقة الأولى بكلية الزراعة، تستخدم HTML وCSS وJavaScript، مع Firebase Authentication وCloud Firestore. تُرفع ملفات الواجهة إلى GitHub، ويمكن نشرها عبر Vercel أو استضافة ثابتة تدعم مجلد `api/`.

## تنظيم المشروع

- `index.html` وبقية ملفات HTML: صفحات المنصة.
- `assets/css/`: ملفات التنسيق.
- `assets/js/`: وحدات JavaScript المستخدمة في الصفحات.
- `assets/images/`: شعار المنصة الأصلي فقط.
- `assets/media/images/`: صور وشرائح تعليمية مستخدمة داخل محتوى الدروس. احتُفظ بها لأنها مرتبطة بالمحتوى الوظيفي، وحذفنا الصور غير المشار إليها.
- `assets/media/video/`: مقاطع الفيديو.
- `assets/pdfs/chemistry/` و`assets/pdfs/math/`: ملفات PDF مرتبة حسب المادة.
- `api/`: وظيفة الاستضافة الخاصة بتصحيح الدرجات.
- `firestore.rules`: قواعد Firestore.
- `docs/`: مستندات المشروع.

## التشغيل والنشر

1. ارفع محتويات المستودع إلى GitHub مع الحفاظ على بنية المجلدات.
2. افتح المشروع عبر خادم تطوير محلي أو اربط المستودع باستضافة ثابتة مثل Vercel. لا تعتمد على فتح ملفات HTML مباشرة (`file://`) لأن Firebase وطلبات الشبكة تحتاج إلى خادم.
3. في Firebase، فعّل الخدمات المستخدمة وأضف نطاق الاستضافة إلى Authentication > Settings > Authorized domains.
4. راجع قواعد `firestore.rules` قبل نشرها على قاعدة بيانات حقيقية.
5. إذا كنت تستخدم وظيفة `api/grade.js`، تأكد أن مزود الاستضافة يدعم وظائف serverless وأن إعدادات البيئة المطلوبة مضبوطة في لوحة الاستضافة، لا داخل المستودع.

## ملاحظات

- ملفات Firebase client configuration الموجودة في الواجهة هي إعدادات تعريفية عامة وليست بديلًا عن قواعد أمان Firestore وقيود Authentication.
- لا تضع مفاتيح خاصة أو كلمات مرور أو رموز وصول في ملفات الواجهة أو المستودع.
- تم نقل الملفات وتحديث المسارات النسبية مع إبقاء الصفحات والوظائف كما هي قدر الإمكان.

## تقرير التعديلات والاختبارات

راجع `docs/CHANGELOG-REORGANIZATION.md` لتفاصيل الملفات المنقولة والمحذوفة ونتائج الفحوصات وحدودها.
