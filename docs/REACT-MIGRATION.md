# تقرير نسخة React

- أُضيفت واجهة React/Vite مع قائمة تنقل عربية RTL.
- احتُفظ بالصفحات الأصلية ومواردها تحت `public/legacy` للحفاظ على وظائفها الحالية أثناء الانتقال.
- لم تُحذف ملفات الصور التعليمية أو ملفات PDF التي تشير إليها الصفحات.
- لم تُنقل ملفات الأصل داخل legacy، لذلك تبقى مساراتها النسبية كما كانت.
- يلزم اختبار نشر Vercel وFirebase على حساب المشروع قبل اعتماد النسخة كبديل نهائي.
- التحويل الكامل للصفحات إلى مكونات React لم يُنفذ في هذه النسخة؛ الواجهة الجديدة تستخدم iframe لعرض الصفحات الأصلية.
