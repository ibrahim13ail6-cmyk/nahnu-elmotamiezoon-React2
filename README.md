# منصة نحن المتميزون — نسخة React

هذه نسخة انتقالية مبنية باستخدام **React + Vite**. توفر واجهة React للتنقل، وتحتفظ بصفحات HTML الأصلية داخل `public/legacy` لتقليل مخاطر كسر وظائف Firebase والاختبارات والمواد أثناء الانتقال. لذلك الصفحات الداخلية نفسها لم تُحوّل بالكامل بعد إلى مكونات React.

## تنظيم المشروع
- `src/`: واجهة React ومكوناتها وتنسيقاتها.
- `public/legacy/`: صفحات HTML الأصلية وملفاتها ومحتواها كما كانت، وتُخدم مباشرة للحفاظ على سلوكها.
- `public/legacy/assets/images/`: شعار المنصة والوسائط التعليمية التي تعتمد عليها الصفحات الأصلية.
- `public/legacy/assets/pdfs/`: ملفات PDF حسب المادة.
- `public/legacy/api/`: واجهة API الأصلية إن كانت بيئة الاستضافة تدعمها.
- `vite.config.js`: إعدادات Vite.

## التشغيل محليًا
1. ثبّت Node.js (إصدار حديث يدعم Vite).
2. شغّل `npm install`.
3. شغّل `npm run dev`.
4. للبناء: `npm run build`، ثم لمعاينة الناتج: `npm run preview`.

## النشر على Vercel
اربط مستودع GitHub بالمشروع، واضبط Framework Preset إلى Vite، وBuild Command إلى `npm run build`، وOutput Directory إلى `dist`. إذا كانت وظيفة `api/grade.js` مطلوبة، راجع نقلها إلى `api/` في جذر المستودع لأن Vite لا ينسخ مجلد `api` تلقائيًا إلى `dist`.

## GitHub
ارفع محتويات هذا المجلد إلى المستودع. لا ترفع `node_modules` أو `dist` عادةً؛ فهما ناتجان عن التثبيت والبناء.

## ملاحظة الانتقال
هذه خطوة React آمنة للحفاظ على السلوك الحالي وليست تحويلًا كاملًا لكل صفحة HTML إلى JSX. يوصى بتحويل الصفحات تدريجيًا إلى `src/pages` واختبار Firebase والمحتوى لكل صفحة قبل إزالة `public/legacy`.
